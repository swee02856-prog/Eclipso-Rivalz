# What is this game? 👾️

A 2d fighting game built in pygame, coded in python.

However, now they want to **KILL** you..

# Why did I make this? 🤔️

For my Terra Week 4 project I wanted to bring back one of my games from before and reuse that genre and create a little lore or story out of it,
I loved my old games shooter genre and shooter system and so I decided to recreate it by making it more "Skillful" like and less "Spammy".

But this time for this game I decided to make an enemy that resembles the player and gives some of that depth that the player works
for some type of organization. 

The game was made using pygame and I love the engine for its simplicity, its very easy to code in, define classes & functions in and reuse code faster.

The Enemy starts off with 100 Health meanwhile the Player has 150, I decided to make this game much easier compared to the older Eclipso Requime.

# Installation

**YOU MUST BE ON A LINUX OPERATING SYSTEM TO PLAY THIS GAME**

If you meet this requirement you can go to releases;

-download the linux executable file **(NOT THE SOURCE CODE)**

# How to play 

**MAKE SURE TO HAVE THE EXECUTABLE FILE DOWNLOADED**

Once downloaded, simply open the executable and you will load into the game and be able to play it.

**OR**

You can clone this repository, install pygame venv and run it that way

# Gameplay Input ⌨️

W -> Jump

D -> Move Right

A -> Move Left

Click -> Shoot

Spacebar -> Jump

Esc -> Main menu/Pause

# Gameplay directions

To Win you must kill the Enemy hitman by shooting them atleast 10 times.

The Enemy Hitman can kill you, he shoots much faster than you and he is more aggressive when his health is low. (He chases you at a closer distance)
